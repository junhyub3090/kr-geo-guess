# 출제 기준과 맵 선택

## 현재 출제 방식

현재 게임은 공식 로드뷰 데이터를 수집하지 않고, 사람이 직접 고른 한국 좌표 풀에서 라운드를 만든다. 시드에는 좌표, 지역, 난이도, 태그, 정답 공개 후 보여줄 일반화된 위치 설명만 저장한다. Kakao Roadview 이미지는 브라우저에서 공식 SDK로만 표시한다.

라운드 생성 흐름:

1. 사용자가 맵을 선택한다.
2. 서버가 `mapId`에 맞는 지역의 시드만 필터링한다.
3. 닉네임, 시간, 선택 맵을 섞은 값으로 결정적 셔플을 만든다.
4. 지역이 겹치지 않도록 먼저 분산 선택하고, 같은 지역 맵에서는 섞인 순서대로 5라운드를 선택한다.
5. 제출 전 공개 라운드 데이터에는 좌표를 넣지 않는다.
6. 제출 후에만 정답 좌표, 거리, 점수를 반환한다.

## 현재 제공 맵

- 한국 전체
- 서울
- 수도권
- 강원
- 경상남도
- 제주
- 충청권
- 전라권
- 경상권

각 맵은 `packages/shared/src/seeds.ts`의 `KOREA_GAME_MAPS`와 `KOREA_SEED_CATALOG`로 관리한다. 새 맵은 지역 목록과 시드만 추가하면 API와 홈 화면에 자동 노출된다.

## 시드 방향

초기 구현의 시청/구청/유명 관광지 중심 위치는 너무 쉽기 때문에 제거했다. 현재 시드는 아래 성격을 섞는다.

- 동네 골목
- 시장 주변
- 해안도로
- 항구 외곽
- 산간/농촌 도로
- 오래된 동네 뒷길
- 한강/호수/강변
- 아파트 단지 외곽
- 산업단지 외곽

정답 공개 전에는 정확한 위치명, 건물명, 관광지명을 공개하지 않는다. 정답 공개 후에도 "서울 서쪽 구릉지 골목"처럼 게임용 설명만 보여주고, 실제 좌표 출처나 상세 지점명은 노출하지 않는다.

## 이동 제한

로드뷰 안에서 무제한 이동하면 표지판과 도로명을 따라가서 쉽게 맞힐 수 있다. 현재 라운드당 파노라마 이동은 5회로 제한한다. Kakao SDK 내부 UI를 뜯어고치지 않고, 공식 이벤트로 파노라마 변경 횟수를 세어 5회를 넘으면 마지막 허용 지점으로 되돌린다.

## 앞으로 더 재밌게 만드는 기준

- 서울과 각 시/도는 승인된 위치 1000개를 목표로 한다.
- 각 지역 풀은 `하/중/상`을 대략 균등하게 유지하고, 실제 게임 난이도는 선택한 모드의 비율로 섞는다.
- 너무 쉬운 랜드마크 정면, 관공서 정문, 역 광장, 유명 관광지 정문은 기본 출제 풀에서 제외한다.
- 위치마다 `easy`, `medium`, `hard` 난이도를 유지하고 방 설정에서 난이도 조합을 고를 수 있게 한다.
- 같은 게임 안에서 해안/도심/골목/산간이 반복되지 않도록 태그 균형을 추가한다.
- 공식 SDK에서 로드뷰가 없는 좌표는 운영 시드에서 제외한다.

대규모 풀은 `data/seed-pipeline`의 후보 생성/감사 흐름으로 관리한다. 자동 수집 후보는 `candidate` 상태로만 남기고, 로드뷰 존재 검증과 사람 검수를 통과한 좌표만 런타임 출제 풀에 반영한다.
