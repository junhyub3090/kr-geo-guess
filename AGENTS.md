# Project Instructions

## UI Direction

- Keep button, tab, selected, and focus states visually flat.
- Do not use raised or 3D button effects such as `translateY`, perspective transforms, inset shadows, or heavy shadows to imply elevation.
- Preserve accessible focus visibility with flat outlines or color changes.
- Keep primary actions close to the thing the user just manipulated. For example, map guess submission belongs directly below or beside the guess map.
- Favor large, stable click targets for repeated game actions; use at least 44px for frequent buttons and color choices when the layout allows it.
- Korean headings and action copy should wrap by word, not by individual syllable, unless a constrained control has no alternative.
