# 디자인 참고 자료

이 문서는 `kr-geo-guess`에 참고할 만한 외부 UI 패턴을 모아두는 목록이다. 새 라이브러리를 추가할 때는 기능 자체보다 현재 앱의 기준인 깔끔함, 직관성, 빠른 게임 동선, 일관된 색과 깊이감에 맞는지 먼저 판단한다.

## Preline Confetti

- 링크: https://preline.co/docs/components/confetti.html
- 참고 포인트: `canvas-confetti` 기반의 가벼운 축하 효과. 버튼 클릭용 예시지만, 우리 앱에서는 멀티 최종 결과에서 1등을 축하하는 자동 이벤트로 변형한다.
- 적용 기준: 전역 캔버스를 명확히 생성하고 애니메이션 종료 후 `reset()`과 DOM 제거까지 처리한다. 색상은 앱 팔레트에 맞추고, 클릭할 때마다 중복 폭죽이 생기지 않게 한다.

## Preline Datamaps

- 링크: https://preline.co/docs/components/datamaps.html
- 참고 포인트: SVG 기반 데이터 지도와 hover tooltip, 색상 상태 표현, 반응형 지도 패턴.
- 적용 기준: 현재 게임 지도는 한국 행정구역 SVG와 맵별 시드 풀에 직접 연결되어 있으므로 Datamaps로 즉시 교체하지 않는다. 다만 랭킹, 지역별 플레이 통계, 운영 대시보드 같은 데이터 지도 화면을 만들 때 참고한다.

## 선택 기준

- 게임 시작, 찍기, 결과 확인 같은 핵심 동선을 더 짧게 만드는가.
- UI가 실제 서비스처럼 절제되어 보이는가.
- 3D 버튼, 과한 그림자, 장식성 그라데이션, 의미 없는 설명문을 늘리지 않는가.
- 모바일과 데스크톱에서 클릭 대상, hover 정보, 텍스트 줄바꿈이 모두 자연스러운가.
- 새 라이브러리를 추가할 만큼 유지보수 이득이 명확한가.
